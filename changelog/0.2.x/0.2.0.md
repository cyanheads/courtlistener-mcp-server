# 0.2.0 — 2026-06-01

## Added

- **`courtlistener_search_financial_disclosures`** — search federal judicial financial disclosure filings by judge person ID and year; returns category counts, itemized gifts, and the source PDF URL. Year filtering is applied client-side (the endpoint does not accept server-side year params). ([#12](https://github.com/cyanheads/courtlistener-mcp-server/issues/12))
- **`courtlistener_get_oral_argument`** — fetch a full oral argument record including speech-to-text transcript, panel judge IDs, duration, and MP3 link. ([#12](https://github.com/cyanheads/courtlistener-mcp-server/issues/12))

## Fixed

- **`courtlistener_get_opinion`** — `case_name`, `court`, and `docket_number` were empty due to a snake_case field mismatch and the cluster endpoint omitting court/docket data; now backfills from the linked docket record. ([#9](https://github.com/cyanheads/courtlistener-mcp-server/issues/9))
- **`courtlistener_get_docket`** — showed raw court URI instead of a human-readable name; now resolved via a bundled court-names map. ([#10](https://github.com/cyanheads/courtlistener-mcp-server/issues/10))
- **`courtlistener_get_judge`** — returned raw single-letter codes for gender, ABA rating, and political affiliation; now expanded to readable labels matching `courtlistener_search_judges` output. ([#11](https://github.com/cyanheads/courtlistener-mcp-server/issues/11))
- **Not-found and rate-limit errors** — previously leaked the full upstream URL in the error message; now classified at a `classifyFetchError` choke point that throws domain errors carrying a machine-readable `reason` + `recovery.hint` with a path-only message. ([#15](https://github.com/cyanheads/courtlistener-mcp-server/issues/15), [#16](https://github.com/cyanheads/courtlistener-mcp-server/issues/16))
- **`courtlistener_get_citations`** — resolved source case name was a `(cluster N)` placeholder; now fetches the real case name from the cluster record. ([#18](https://github.com/cyanheads/courtlistener-mcp-server/issues/18))
