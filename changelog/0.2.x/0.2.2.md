# 0.2.2 — 2026-06-04

## Added

- **`courtlistener_get_parties`** tool ([#20](https://github.com/cyanheads/courtlistener-mcp-server/issues/20)) — fetches all parties and attorneys of record for a RECAP federal docket by docket ID. Returns each party's name, docket-scoped role (Plaintiff, Defendant, Petitioner, Respondent, etc.), and attorneys with contact information. Two upstream calls per invocation: `GET /parties/` then a batch `GET /attorneys/?id=…` for attorney names and contact details. Paginate with `page` and `page_size` (max 10 parties per page).
- **`AttorneyRelationship`, `AttorneyDetail`, `PartyType`, `Party`** types in `courtlistener-service` — upstream wire shapes and assembled output type for the parties/attorneys workflow.
- `recoveryHintForPath` now maps `/parties/` paths to a RECAP-coverage hint.
- `CourtListenerService.get()` extended to accept `number[]` values — serialized as repeated query params (e.g. `id=1&id=2`) for batch attorney lookup.
