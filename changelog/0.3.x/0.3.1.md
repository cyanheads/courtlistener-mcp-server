# 0.3.1 — 2026-07-10

## Fixed

- **`courtlistener_get_docket`** — docket entries were capped to the first upstream page (a fixed 20 rows) with no way to reach the rest of a large docket. A new `entries_page` input pages through `/docket-entries/` (page-number pagination), and a `next_cursor` output field returns the next page number (`null` on the last page); the continuation is surfaced in `content[]`. The `entries_page_size` description is corrected — CourtListener ignores it and always returns 20 entries per page. [#32](https://github.com/cyanheads/courtlistener-mcp-server/issues/32)
- **`courtlistener_get_citations` / `courtlistener_search_financial_disclosures` `page_size`** — the descriptions implied pages as small as 1, but CourtListener enforces a 20-result minimum on `get_citations` (`direction="cited_by"`) and `search_financial_disclosures`; both now document the floor and default to 20. `get_citations` `direction="citing"` slices the cited-opinion list before querying, so it is documented as returning at most `page_size` results. [#33](https://github.com/cyanheads/courtlistener-mcp-server/issues/33)
