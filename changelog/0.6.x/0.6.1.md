# 0.6.1 — 2026-07-30

## Added

- **`courtlistener_get_judge`** — enrichment fields `positionsShown` and `truncated` report whether the position walk hit its bound; a `notice` explains it when it does. [#64](https://github.com/cyanheads/courtlistener-mcp-server/issues/64)
- **`courtlistener_lookup_citation`** — `max_court_lookups` input (0–20, default 4) lets the caller raise or skip the per-call court-backfill budget. Each cluster's new `court_resolution` field (`resolved` / `no_docket` / `lookup_failed` / `over_budget`) distinguishes a budget-exhausted lookup from a genuinely failed one. [#66](https://github.com/cyanheads/courtlistener-mcp-server/issues/66)
- **`courtlistener_lookup_courts`** — `all_matching_court_ids` returns the complete filtered court-id set at no request cost, from a new full snapshot (`scripts/generate-court-names.ts`, `bun run courts:snapshot`) covering all 3,359 CourtListener courts with jurisdiction, in-use, and opinion-scraper attributes — up from 471 active-bench-only. `all_matching_court_ids_complete` distinguishes a withheld-because-over-1,000 list from a genuinely empty one. [#65](https://github.com/cyanheads/courtlistener-mcp-server/issues/65)

## Changed

- **`courtlistener_get_judge`** — `/positions/` is now cursor-walked up to 5 pages instead of a single fixed-size fetch; the endpoint declares no `pagination_class` of its own, so a `page_size: 50` request parameter has never had any effect and is now dropped. [#64](https://github.com/cyanheads/courtlistener-mcp-server/issues/64)
- **`courtlistener_lookup_citation`** — the docket court-backfill walk is now sequential and aborts on the first rate-limited response, instead of issuing the whole budget as a concurrent burst that would 429 in lockstep. [#66](https://github.com/cyanheads/courtlistener-mcp-server/issues/66)
- **Internal** — verified the documented CourtListener free-tier ceiling (5/min, 50/hour, 125/day) against upstream's published tiers; four code comments (search tool definitions) now carry the same tier-variance caveat the caller-facing copy already had. No functional change. [#60](https://github.com/cyanheads/courtlistener-mcp-server/issues/60)

## Fixed

- **`courtlistener_lookup_citation`** — the docket court-resolution diagnostic log reported the budgeted docket count where it meant the count actually resolved.
