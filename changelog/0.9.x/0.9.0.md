# 0.9.0 — 2026-10-31

## Added

- **`courtlistener_get_docket`** accepts `document_ids` from the requested entries page and returns embedded filing text, source links and extraction status through bounded retrieval; selection verifies docket ownership without document-detail requests or page walks ([#80](https://github.com/cyanheads/courtlistener-mcp-server/issues/80)).
- **`courtlistener-guide`** adds the `skill://courtlistener-guide/SKILL.md` research resource for identifier chains and completeness checks, also delivered through plugin installs, npm, Docker and the desktop bundle.
- **Agent Plugins** adds root `plugin.json` and `mcp.json` alongside the existing client overlays.

## Changed

- **Docket output schema:** Listing-only properties become optional to represent selected responses in the same tool; calls without `document_ids` retain their listing values.
- **Research guidance** distinguishes cluster, opinion, docket and document identifiers, citation links from legal treatment, and source completion from retrieval completion; README setup uses one local configuration and separates Docker/source instructions.
- **Development tooling** syncs framework skills and packaging checks, preserves SDK runtime modules beneath nested `skills` paths, and strips dependency build-only files from desktop bundles.
- **Dependency age policy** uses a one-day minimum release age; Bun tooling and images move from 1.4.3 → 1.4.4.

## Fixed

- **Opinion continuation** derives primary identity and coordinates before optional docket backfill; changing backfill no longer invalidates new primary cursors. Source changes still reject stale cursors; oversized backfill uses independent `enrichment_cursor` coordinates and `source_id`, and legacy v1 cursors retain their original behavior ([#83](https://github.com/cyanheads/courtlistener-mcp-server/issues/83)).
