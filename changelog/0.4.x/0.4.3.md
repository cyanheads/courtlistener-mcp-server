# 0.4.3 — 2026-07-16

## Fixed

- **`courtlistener_get_oral_argument` `sections` validation order** — the `unknown_section` check ran after `svc.getOralArgument()` fetched the record, spending an upstream request on a section name that could never match (`SECTION_NAMES` is a fixed list resolved at module load, so the check never depended on the fetched record). The check now runs before the fetch, so a request naming an invalid section is rejected without touching the network. [#41](https://github.com/cyanheads/courtlistener-mcp-server/issues/41)
