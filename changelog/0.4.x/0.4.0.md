# 0.4.0 — 2026-07-10

## Added

- **`courtlistener_get_financial_disclosure`** — itemized companion to `courtlistener_search_financial_disclosures`. Fetch one disclosure's investments, debts, positions, reimbursements, non-investment/spouse income, agreements, and gifts by `disclosure_id`; coded income/value/valuation-method columns decode to readable dollar ranges (e.g. `N` → `$250,001 - $500,000`). `categories:[...]` selects specific rows; omitting it returns everything, or an outline of categories by size with a re-call contract when the full itemization exceeds the inline budget. [#34](https://github.com/cyanheads/courtlistener-mcp-server/issues/34)

## Fixed

- **LICENSE** — the Apache-2.0 license text was declared in `package.json`'s `license` field and `files[]` array since scaffolding, but the file itself was never committed; the published npm package now ships it.
