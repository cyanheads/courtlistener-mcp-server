# 0.10.0 — 2026-11-13

## Added

- **Citation filters** accept multiple `statuses` and a `filed_before` date in both directions. Use `order_by` for `cited_by`, or omit `statuses` for the Published default. ([#85](https://github.com/cyanheads/courtlistener-mcp-server/issues/85))
- **Docket listings** include `cluster_ids`, `audio_ids`, `date_argued`, `suit_nature`, `appeal_from`, and `date_last_filing`. ([#88](https://github.com/cyanheads/courtlistener-mcp-server/issues/88))
- **Opinion retrieval** accepts `text: "plain"` or `"html"` and labels outline variants with `type_label`, `author_id`, and `per_curiam`. Preserve the text mode across continuations. ([#91](https://github.com/cyanheads/courtlistener-mcp-server/issues/91))

## Changed

- Docket search roster arrays and opinion search citation ID arrays are now opt-in through `include`. Restore them with `include: ["parties", "attorneys", "firms"]` on docket search and `include: ["cites"]` on opinion search. ([#92](https://github.com/cyanheads/courtlistener-mcp-server/issues/92))
- **Docket search** returns `party_count`, `attorney_count`, and `firm_count` by default. Null means the source array was absent.
- **Retrieval continuations** reuse matching source for five minutes and return `source_fetched_at`. First calls still fetch fresh source, and opinion docket enrichment remains live. ([#90](https://github.com/cyanheads/courtlistener-mcp-server/issues/90))
- **Tool guidance** covers `q: "*"` for filter-only searches, approximate docket search totals, numeric entries-page continuations, and disclosure line-item retrieval. ([#93](https://github.com/cyanheads/courtlistener-mcp-server/issues/93))
- **Bun** now requires `>=1.4.4` (previously `>=1.4.0`).
- **Desktop bundles** preserve SDK skill modules when stripping dependency documentation. Development tooling and framework skills track the adopted framework.

## Fixed

- **Opinion and oral-argument search** request highlighted match context from CourtListener and render the returned excerpts as readable text. ([#86](https://github.com/cyanheads/courtlistener-mcp-server/issues/86))
- **Court filters** accept space- or comma-separated IDs and normalize known IDs case-insensitively. ([#87](https://github.com/cyanheads/courtlistener-mcp-server/issues/87))
- **Retrieval URLs** render as navigable links when complete. Oral-argument detail also returns CourtListener's durable MP3 URL as `local_path`. ([#89](https://github.com/cyanheads/courtlistener-mcp-server/issues/89))
- **Citing pagination** identifies empty pages with continuations, and **rate-limit errors** identify the paced request that was never sent.

## Dependencies

- deps: `@cyanheads/mcp-ts-core` `^0.13.18` → `^0.13.22`; `parse5-sax-parser` `8.0.0` → `8.0.1`; `@biomejs/biome` `2.6.4` → `2.6.7`; `tsc-alias` `^1.9.9` → `^1.9.10`; `vitest` `^5.0.5` → `^5.1.0`.
- **Framework errors** redact raw upstream response bodies and preserve recognized query diagnostics.
