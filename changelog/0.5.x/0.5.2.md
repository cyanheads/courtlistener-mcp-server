# 0.5.2 — 2026-07-29

## Changed

- **Rate-limit copy** — README, `docs/design.md`, `docs/idea.md`, `courts-reference.resource.ts`, and the `legal-research` prompt now attribute the 5/min, 50/hr, 125/day figures to CourtListener's published free tier rather than asserting them as measured, and correct stale per-invocation request-cost claims to match what the code actually spends.

## Fixed

- **`courtlistener_get_citations` (`cited_by`)** — `getCitedBy` queried `cites:(<cluster_id>)`, but the `/search/` `cites` field keys on *opinion* IDs, not cluster IDs; when the two diverge, the tool returned an empty network indistinguishable from a genuinely uncited case, with a recovery hint that misdirected the caller toward doubting the cluster ID. It now resolves the cluster's opinion IDs via `getOpinionCluster` and builds `cites:(id1) OR cites:(id2) …`, also returning `sourceCaseName` from that same fetch and removing the redundant duplicate `/clusters/{id}/` fetch `getClusterCaseName` made just for `cited_by`'s case name. [#58](https://github.com/cyanheads/courtlistener-mcp-server/issues/58)
- **`getOpinionCluster` sub-opinion pagination** — `/opinions/?cluster=<id>` is cursor-paginated; a single fixed `page_size: 20` fetch dropped every variant past the first page, shortening the opinion outline and both citation directions' ID lists with nothing on the response to say so. `getOpinionCluster` now walks the cursor up to `SUB_OPINION_PAGE_LIMIT` (5) pages, warning when the bound is hit with a cursor still outstanding. This is the sub-opinion-truncation half of #48 only — the `type`-code expansion half is a separate, later change, and #48 stays open. [#48](https://github.com/cyanheads/courtlistener-mcp-server/issues/48)
- **`courtlistener_get_citations` (`citing`)** — the empty-results enrichment notice now distinguishes a page with no matches under the active filters, with more pages to check, from a genuinely exhausted citation network; `totalCount`'s description now states that it counts opinions before filtering for `citing` and filtered clusters for `cited_by`. [#56](https://github.com/cyanheads/courtlistener-mcp-server/issues/56)
