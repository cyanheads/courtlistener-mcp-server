# 0.5.3 — 2026-07-30

## Added

- **`courtlistener_get_judge` position decoding** — `position_type`, `termination_reason`, and `degree` keep their raw CourtListener code and gain `position_type_label` / `termination_reason_label` / `degree_label` twins, decoded via new lookup tables covering the full `Position.POSITION_TYPES`, `Position.TERMINATION_REASONS`, and `Education.DEGREE_LEVELS` enums. `job_title` and `organization_name` are new standalone fields so non-judicial roles (private practice, prosecutor, professor) render instead of collapsing to an empty position row. [#46](https://github.com/cyanheads/courtlistener-mcp-server/issues/46)
- **`courtlistener_get_judge` date granularity** — `dob_granularity`, `dod_granularity`, and per-position `date_start_granularity` / `date_termination_granularity` report the precision (`year`, `month`, `day`) CourtListener actually recorded, decoded from the `DATE_GRANULARITIES` values upstream serves alongside each date. [#47](https://github.com/cyanheads/courtlistener-mcp-server/issues/47)
- **`courtlistener_get_opinion` type decoding** — `type` keeps the raw `/opinions/` code (e.g. `030concurrence`) and gains `type_label`, decoded through the same `o_type_index_map` labels `courtlistener_search_opinions` already serves, so both tools agree on the label for the same opinion variant. Completes [#48](https://github.com/cyanheads/courtlistener-mcp-server/issues/48) (the sub-opinion-pagination half shipped in 0.5.2).
- **`src/services/courtlistener/codes.ts`** — `expandCode` extracted from `get-judge.tool.ts` into a shared, case-insensitive code-to-label helper, now used by `get-judge.tool.ts`, `get-opinion.tool.ts`, and `courtlistener-service.ts`'s attorney-role expansion.

## Fixed

- **`courtlistener_get_judge` education year** — `education[].year` read `graduation_year`, a key `/people/` never serves; the populated column is `degree_year`. Every returned record had a null year. [#62](https://github.com/cyanheads/courtlistener-mcp-server/issues/62)
- **`courtlistener_get_judge` date rendering** — a year-only or month-only `dob`/`dod`/position date is stored by CourtListener as `YYYY-01-01` or `YYYY-MM-01`; the tool now renders each date to its recorded granularity instead of asserting a day of birth, death, or appointment the record never claimed. [#47](https://github.com/cyanheads/courtlistener-mcp-server/issues/47), [#63](https://github.com/cyanheads/courtlistener-mcp-server/issues/63)
- **`courtlistener_get_judge` blank-field nullability** — `degree`, `termination_reason`, `dob_city`, and `dob_state` are blank-able CharFields upstream (`blank=True`, no `null=True`), so an unrecorded value arrived as `""` instead of the `null` these fields already documented. Normalized to `null` to match the schema and the new `_label` fields, which already returned `null` for the same case.
