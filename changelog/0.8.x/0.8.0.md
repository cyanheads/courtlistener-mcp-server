# 0.8.0 — 2026-10-18

## Changed

- **Opinion, oral-argument, and disclosure retrieval** now bounds each completed response surface to 24,000 UTF-8 bytes, including explicitly selected sections and metadata; follow `retrieval.next_cursor` with the original ID and selection ([#77](https://github.com/cyanheads/courtlistener-mcp-server/issues/77)).
- **Partial outputs** add `kind: "page"` and may omit metadata strings/arrays or row text; reconstruct omitted values using JSON Pointer paths in `retrieval.ranges` and `text_chunks`. Changed source content rejects a stale cursor with a restart hint.
- **Citation completeness** exposes `source_variants_completion`, `observed_total`, and `total_is_partial`; incomplete source variants omit the exact `totalCount` enrichment.
- **Page-size requests** accept oversized positive integers, bound outgoing sizes to existing caps, preserve upstream pages, and expose requested/bounded/actual sizing on both surfaces ([#81](https://github.com/cyanheads/courtlistener-mcp-server/issues/81)).
- **Framework tooling and packaging** sync development skills and checks, correct npm registry launch configuration, use Bun 1.4.3 images, and remove musl-only image dependencies.

## Fixed

- **Docket totals:** Return `total_entries: null` when CourtListener does not provide a numeric docket-entry total ([#14](https://github.com/cyanheads/courtlistener-mcp-server/issues/14)).
- **Court and disclosure labels** preserve unknown strings instead of resolving inherited object properties ([#74](https://github.com/cyanheads/courtlistener-mcp-server/issues/74)).
- **Citing cursors** reject empty strings and malformed, negative nonzero, fractional, exponential, hexadecimal, or unsafe offsets before I/O; valid decimal integer spellings remain accepted, and exhausted offsets return an empty page without searching ([#75](https://github.com/cyanheads/courtlistener-mcp-server/issues/75)).
- **Publication status** sends the correct `In-chambers` and `Relating-to` query keys; omitted status uses CourtListener's Published default ([#76](https://github.com/cyanheads/courtlistener-mcp-server/issues/76)).
- **Opinion text** derives readable fallback text from markup while preserving supplied plain text and raw source; snippets decode entities, and rendering escapes literal Markdown and fences raw markup ([#78](https://github.com/cyanheads/courtlistener-mcp-server/issues/78)).
- **Source and enrichment completion** distinguishes capped variant/attorney walks, exhausted attorney misses, empty source fields, and sanitized docket lookup failures; cancellation propagates. A later local-budget refusal retains fetched attorney details and their remaining roster cursor ([#79](https://github.com/cyanheads/courtlistener-mcp-server/issues/79)).
