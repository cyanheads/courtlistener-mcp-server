# 0.7.1 — 2026-08-24

The wire changes below arrive with `@cyanheads/mcp-ts-core` `^0.12.3`.

## Added

- **`courtlistener://reference/courts` returns a cache hint** — `ttlMs` 24h, `cacheScope: 'public'`. The document is compiled into the build, so it cannot change until the server is redeployed. 2026-07-28 clients only; 2025-era reads are unaffected.
- **`.github/CONTRIBUTING.md` and `.github/CODE_OF_CONDUCT.md`.**

## Changed

- **Tool inputs are strict** — an argument key a tool does not declare is rejected by name before the handler runs, and every advertised `inputSchema` carries `additionalProperties: false`. Root level only; a nested object still strips.
- **The advertised `outputSchema` declares the error envelope** — success fields become optional and `error` is declared, so a client that validates `structuredContent` without checking `isError` stops rejecting error results with `-32602`.
- **Advertised JSON Schema is 2020-12**, not draft-07, and the HTTP endpoint serves protocol revision `2026-07-28` alongside the 2025 revisions.
- **`ctx.log` reaches the client** as `notifications/message`, gated by the client's `logging/setLevel`.
- **`MCP_SESSION_MODE` is documented in the README env table**, and `.env.example` points at `stateless` — the mode the published Docker image already sets.
- **Security reports go to `security@caseyjhand.com`.**
- **The Docker build stage pins `--platform=$BUILDPLATFORM`.** Only `dist/` is copied forward and `bun run build` emits platform-independent JavaScript, so the cross-arch leg of a multi-arch build no longer runs under QEMU, where Bun's JavaScriptCore aborts on a spurious `MemoryExhaustion` assertion.
- **Both production installs pass `--omit=peer`** — the runtime image stops carrying the framework's optional peer tiers. The flag is needed on the OTEL `bun add` too, which otherwise re-resolves the graph and pulls them back in.
- **`tests/` is typechecked** — `tsconfig.json` covers `src/` and `tests/` under `noEmit`, and `tsconfig.build.json` carries the emit path. The typecheck caught an `opinions_cited` fixture modeled as objects rather than the resource-URI strings upstream returns; `get_opinion`'s cite extraction now has coverage.
- **Build-time gates:** `courtlistener_lookup_citation` is exempted from the linter's `capped-list-no-truncation` rule via `MCP_LINT_TRUNCATION_ALLOWLIST`, and the `typescript` hold leaves `devcheck.config.json`'s outdated allowlist.
