# 0.7.3 — 2026-09-30

## Changed

- **Docker image** — production dependencies install in a `deps` stage on `$BUILDPLATFORM`, cross-installed with `--os`/`--cpu` under `bunfig.toml`'s release-age gate and security scanner, so a multi-arch build no longer runs Bun under emulation. `MCP_FORCE_CONSOLE_LOGGING` is no longer set.
- **Image OpenTelemetry packages** — `scripts/install-otel.ts` installs them at the framework's declared peer ranges, log exporters included, in place of the list the `Dockerfile` kept by hand.
- **Bundle and tarball contents** — `.mcpbignore` keeps `docs/idea.md` and `logs/` out of the `.mcpb` bundle, and `package.json` `files` keeps `dist/*.mcpb` out of the npm tarball.
- **Docs** — the README capability reference lists each tool's inputs and returned fields; the README config table and `.env.example` cover `OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT`, `LOG_TOOL_FAILURE_PAYLOADS`, and `LOG_TOOL_FAILURE_PAYLOAD_MAX_BYTES`; `CLAUDE.md` / `AGENTS.md` declare the gated release PR mode.
- **`scripts/` and `framework-skills/` match `@cyanheads/mcp-ts-core` 0.13.10** — `lint:mcp` fails on a definition file it cannot import or an unparseable `server.json`, `lint:packaging` checks the `manifest.json` version and the Dockerfile build platform, and `release:github -- --check` validates a tag annotation.
- A stray closing-tag line is gone from the end of the 0.5.0, 0.5.1, and 0.5.2 changelog entries.

## Fixed

- **Query syntax errors are `invalid_query`** ([#70](https://github.com/cyanheads/courtlistener-mcp-server/issues/70)) — a query CourtListener rejects for unbalanced parentheses or quotes, an unrecognized proximity token, a disallowed wildcard pattern, or an invalid date format now fails `courtlistener_search_{opinions,dockets,judges,oral_arguments}` as `ValidationError` (`-32007`) with `data.reason: "invalid_query"`, the diagnostic in `data.detail`, and a recovery hint. Other 400 responses are classified as before.
- **Unmapped codes named like inherited object properties pass through** ([#72](https://github.com/cyanheads/courtlistener-mcp-server/issues/72)) — `expandCode` resolves only a label table's own entries, so a code such as `constructor` or `__proto__` comes back as itself. `courtlistener_get_judge` and `courtlistener_get_opinion` failed on such a value.
