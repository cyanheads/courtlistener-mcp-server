# 0.7.0 — 2026-07-30

## Added

- **`jurisdiction`** now accepts nine codes upstream defines that the enum omitted — `TRS`, `TRA`, `TRT`, `TRX`, `TS`, `TA`, `TSP`, `MA`, `MT` — reaching the tribal, territory, and military courts no prior value could filter to.
- **`src/services/courtlistener/jurisdictions.ts`** — single source for `COURT_JURISDICTION_CODES` and `COURT_JURISDICTION_LABELS`, now read by the tool input, the `courtlistener://reference/courts` resource, and `docs/design.md` in place of three hand-maintained copies.
- **`listUnclassifiedCourtIds()`** in `court-names.ts` — names snapshot courts whose stored `jurisdiction` matches no upstream choice at all (`njcirctsussex`, `ohctapp1`); the tool description now surfaces both, since no `jurisdiction` value reaches them.

## Changed

- **`S`** relabeled State Supreme (was "State (other)"); **`SS`** relabeled State Special (was mislabeled "State Supreme"). The two were effectively swapped — a caller filtering on `SS` for state supreme courts was receiving state special courts; switch to `S`.
- **`TT`** relabeled Territory Trial (was "Tribal/Territory"); **`C`** relabeled Committee (was "Circuit (historical)").
- **`courtlistener://reference/courts`** jurisdiction table now renders from the same choice set the tool input validates against, so the two can no longer drift apart.

## Removed

- **`T` and `SAL`** no longer accepted by `jurisdiction`. `T` (Testing) is excluded from every `/courts/` response by `CourtViewSet.queryset`, so the filter could only ever return zero rows; `SAL` was never one of upstream's own choices — the API rejects it with a 400. Callers passing either value must drop the filter or switch to an accepted code.
