# 0.1.0 — 2026-05-25

## Added

- **`courtlistener_search_opinions`** — full-text search across 9M+ written court opinions; field syntax (`caseName:`, `court_id:`, `judge:`, `cites:(id)`), status filter, sort, cursor pagination
- **`courtlistener_get_opinion`** — fetch full text and metadata for an opinion cluster including all opinion variants (majority, concurrence, dissent)
- **`courtlistener_get_citations`** — citation network traversal in `cited_by` and `citing` directions; court and date filters; cursor pagination
- **`courtlistener_lookup_citation`** — resolve a legal citation string (e.g., "410 U.S. 113") to a cluster ID via `/citation-lookup/`
- **`courtlistener_search_dockets`** — search RECAP federal dockets by query, party name, court, and date; returns up to 3 sample document entries per docket
- **`courtlistener_get_docket`** — fetch full docket metadata and entry list for a single federal case
- **`courtlistener_search_judges`** — search judge records by name, appointing president, court, and political affiliation
- **`courtlistener_get_judge`** — fetch full biographical profile, appointment history across all courts, education, and ABA ratings
- **`courtlistener_lookup_courts`** — list courts by jurisdiction type and active-scraper status; returns `court_id` strings for use in search filters
- **`courtlistener_search_oral_arguments`** — search appellate oral argument audio recordings; returns MP3 download URL, duration, and transcript snippet
- **`CourtListenerService`** — REST API v4 client with auth, exponential-backoff retry, and 429 rate-limit error classification by minute/hour/day window
