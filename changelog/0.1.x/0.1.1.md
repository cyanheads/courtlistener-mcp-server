# 0.1.1 — 2026-05-25

## Fixed

- **`courtlistener_get_opinion`** — `/clusters/{id}/` returns `sub_opinions` as URI strings; added secondary fetch to `/opinions/` to resolve actual opinion objects before returning
- **`courtlistener_get_docket`** — `/dockets/{id}/` does not include entries inline; added secondary fetch to `/docket-entries/` to populate `docket_entries` in the response
- **`courtlistener_get_judge`** — `/people/{id}/` returns positions as URI strings; added secondary fetch to `/positions/` to populate full position records with nested `court` object; fixed `court` / `court_id` extraction from nested court object; fall back to `name_first + name_last` when `name_full` is null
- **`courtlistener_get_citations`** — `opinions_cited` are URI strings, not objects; added regex extraction of numeric IDs from citation URI strings
- **`courtlistener_lookup_citation`** — updated response normalization to match actual `/citation-lookup/` response shape (`citation`, `normalized_citations`, `clusters[]`)
- **`CourtListenerService`** — added explicit 404 handling; returns `notFound` error before the generic non-OK branch
- **Service initialization** — removed `Object.assign` hack; pass server config directly to `initCourtListenerService`
- **`courtlistener_get_judge` output schema** — corrected `fjc_id` type from `z.string()` to `z.number()`
