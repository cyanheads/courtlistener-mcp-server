# 0.1.5 — 2026-05-30

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.13 → ^0.9.16` — picks up enrichment block support (`ctx.enrich.*`), per-tool `enrichment:` schema declaration, and typed agent-facing context surfaced in both `structuredContent` and `content[]`.
- **`total_count` → `enrichment.totalCount`** (structuredContent key rename) — on `courtlistener_search_dockets`, `courtlistener_search_judges`, `courtlistener_search_opinions`, `courtlistener_search_oral_arguments`, `courtlistener_lookup_courts`, and `courtlistener_get_citations`: the total was moved from `output.total_count` to the typed `enrichment` block as `totalCount` (true upstream total, not page count); value preserved in both channels.
- **`courtlistener_search_opinions`** gains `enrichment.effectiveQuery` — echoes the query string sent to CourtListener.
- **`courtlistener_lookup_citation`** gains `enrichment.queriedCitation` — echoes the citation string looked up.
- **Empty-result guidance** — all affected search/list tools now emit `enrichment.notice` (optional) when the result set is empty, surfacing applied filter context and concrete next steps for the agent.

## Fixed

- **`courtlistener_lookup_courts` count** — `totalCount` now reports the upstream total (all courts matching the filter) rather than the number of courts on the current page.
- **`courtlistener_get_docket` entry count** — `total_entries` now reflects the true entry count from the `/docket-entries/` endpoint, not the fetched page size.
